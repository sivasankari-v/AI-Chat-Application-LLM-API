### 📖 Project Overview
This project demonstrates the integration of Large Language Models (LLMs) via API to build a fully functional, interactive AI Chat Application. It fulfills all the requirements of **Module 3: LLM APIs & App Development**.

The application is not just a simple chatbot; it includes production-level features like cost control, custom instructions, and state management.

### ✨ Key Features (Module 3 Requirements Covered)

-   **LLM API Integration:** Integrated with Groq's ultra-fast `Llama-3.1-8b-instant` model.
-   **Prompt Engineering:** Custom System Prompt to define AI personality and role.
-   **Hyperparameter Control:** 
    -   `Temperature` Slider (0.0 - 1.0) to control creativity vs. factuality.
    -   `Max Tokens` Slider for Cost Control & Response Length Management.
-   **Advanced Chat Management:**
    -   Persistent Chat History using `st.session_state`.
    -   Real-time Token Usage & Cost Tracking.
    -   Clear Chat Functionality.
-   **Professional UI/UX:** Built with Streamlit for a clean, ChatGPT-like interface.

### 🛠️ Tech Stack
-   **Frontend:** Streamlit
-   **LLM Provider:** Groq API (Free Tier)
-   **Model:** Llama 3.1 8B Instant & Llama 3.3 70B Versatile
-   **Language:** Python
